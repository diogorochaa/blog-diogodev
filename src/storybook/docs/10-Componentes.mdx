## Componentes com wrapper async

- `Header` busca indice de posts e paginas ativas no Prismic; `HeaderShell` recebe dados prontos para testes/stories.
- `Footer` busca paginas ativas no Prismic; `FooterShell` recebe links prontos para testes/stories.
- `SliceRenderer` roda no servidor e busca `PostService` ou `GithubService` apenas quando o slice dinamico precisa.

## Padrao recomendado para novos componentes

1. Criar `Componente.tsx`
2. Criar `Componente.types.ts`
3. Exportar no `index.ts` da pasta
4. Documentar neste catalogo e, quando aplicavel, adicionar `*.stories.tsx`
