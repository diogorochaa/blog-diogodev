# Mapa de paginas (App Router)

## Rotas principais

| Rota                   | Arquivo principal                        | Responsabilidade                                                       |
| ---------------------- | ---------------------------------------- | ---------------------------------------------------------------------- |
| `/`                    | `src/app/page.tsx`                       | Home "career mode": hero, ficha, temporada, partidas, GitHub, tatica, carreira, trofeus, extra e artigos |
| `/about`               | `src/app/about/page.tsx`                 | Ficha do jogador + repositorios GitHub + JSON-LD de pessoa               |
| `/projects`            | `src/app/projects/page.tsx`              | Lista de projetos do Prismic e repositorios do GitHub                  |
| `/projects/[uid]`      | `src/app/projects/[uid]/page.tsx`        | Relatorio da partida (projeto), metadata dinamica e `notFound()`              |
| `/career`              | `src/app/career/page.tsx`                | Linha do tempo completa e JSON-LD `ProfilePage`                        |
| `/blog`                | `src/app/blog/page.tsx`                  | Arquivo de artigos (primeira pagina) com categorias                    |
| `/blog/page/[page]`    | `src/app/blog/page/[page]/page.tsx`      | Paginacao do arquivo                                                   |
| `/blog/tag/[tag]`      | `src/app/blog/tag/[tag]/page.tsx`        | Artigos filtrados por tag                                              |
| `/blog/[slug]`         | `src/app/blog/[slug]/page.tsx`           | Artigo (stage), indice, navegacao entre stages e `notFound()`          |
| `/[slug]`              | `src/app/[slug]/page.tsx`                | Redirect 308 das URLs antigas de posts para `/blog/[slug]`             |
| `/pages/[uid]`         | `src/app/pages/[uid]/page.tsx`           | Paginas editoriais montadas com slices do Prismic                      |

`/page/[n]` redireciona para `/blog/page/[n]` pela regra `redirects()` de
`next.config.mjs`.

## Modulos por rota

### Home (`src/app`)

- `home.data.ts`: agrega Prismic (`home`, `about`, `profile`, `project`, `career`, `interest`), GitHub e JSON-LD
- `HomePageContent.tsx`: secoes da home e menu principal (somente secoes com dados)

### About (`src/app/about`)

- `about.data.ts`: conteudo do `about`, identidade do jogador, repositorios e JSON-LD
- `AboutPageContent.tsx`: apresentacao da pagina

### Projetos (`src/app/projects`)

- `projects.data.ts` / `ProjectsPageContent.tsx`: listagem
- `[uid]/project.data.ts`: static params, busca por UID, metadata e JSON-LD `CreativeWork`
- `[uid]/ProjectPageContent.tsx`: match report (pre-jogo, estrategia, esquema tatico, decisoes, lances dificeis, pos-jogo)

### Carreira (`src/app/career`)

- `career.data.ts`: metadata, dados e JSON-LD
- `CareerPageContent.tsx`: `CareerTimeline` completa

### Blog (`src/app/blog`)

- `blog.constants.ts` / `blog.data.ts`: titulo, posts por pagina e montagem do `BlogArchive`
- `page/[page]/page.data.ts`: parse de params, static params e metadata
- `tag/[tag]/tag.data.ts`: static params, metadata e posts por tag
- `[slug]/post.data.ts`: busca por slug, metadata, JSON-LD e stages vizinhos
- `[slug]/PostPageContent.tsx`: artigo, indice e `StageNav`
- `[slug]/SlugNotFoundContent.tsx`: `GameOver` com artigos recomendados

### Paginas editoriais (`src/app/pages/[uid]`)

- `page.tsx`: resolve `uid`, metadata, static params e `notFound()`
- `page.data.ts`: busca `page`, metadata, JSON-LD e static params
- `EditorialPageContent.tsx`: cabecalho editorial e `SliceRenderer`
- `page.types.ts`: contratos locais da rota

## Arquivos estruturais de SEO e shell

| Arquivo                         | Papel                                   |
| ------------------------------- | --------------------------------------- |
| `src/app/layout.tsx`            | Root layout global                      |
| `src/app/robots.ts`             | Politica de rastreamento para bots      |
| `src/app/sitemap.ts`            | Sitemap com rotas estaticas, posts, tags e projetos |
| `src/app/not-found.tsx`         | 404 global (`GameOver`)                 |
| `src/app/error.tsx`             | Erro global com retry                   |
| `src/app/RootLayoutContent.tsx` | Conteudo de apresentacao do layout      |
